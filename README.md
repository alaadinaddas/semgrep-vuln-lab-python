- SQL injection
- Command injection
- XSS-like reflection
- Unsafe eval
- Insecure randomness
- Unsafe yaml.load
- Insecure deserialization
- Hardcoded secrets

Your task is to scan this code with Semgrep, understand the findings, and fix some of them.
